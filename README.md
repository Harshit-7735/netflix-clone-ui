# Netflix Clone UI (Flexbox)

A responsive Netflix homepage clone using **Flexbox**. This project replicates the Netflix homepage layout, showcasing various rows of movie posters, with a simple navbar and hero section. It is built to learn and practice **CSS Flexbox**, **responsive design**, and **UI development**.


## 💻 Technologies Used

- **HTML**: Structure of the page
- **CSS**: Styling using **Flexbox**
- **Flexbox**: Layout for a responsive and clean design
- **Responsive Design**: Ensures the page looks good on all screen sizes

## 🚀 Features

- **Hero Section**: Netflix-style background image with a title and buttons
- **Navbar**: A simple navigation bar with hover effects
- **Movie Rows**: Displays movie posters in a row with horizontal scroll
- **Fully Responsive**: Optimized for mobile, tablet, and desktop views
